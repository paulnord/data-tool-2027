The Linux downloads are alternatives; you do not need both. Windows ARM and Linux ARM builds are not included. GitHub’s **Source code** downloads below are for developers, not installers.

**This is a development preview.** The Windows installer is unsigned and the Mac app is not Apple-notarized, so your operating system may show a security warning or block opening it. Native file dialogs, file associations and printing still need testing on each target platform; build targets are not guarantees of compatibility with every OS version.

**Getting started:** open **Data → Load file** to find the bundled example files, or load your own CSV data. Fitting runs locally; no student data is uploaded.

**Saving your work:** single-fit sessions and CSV data can be saved. Multi-interval and collision setups are still in-memory drafts—copy or print their reports before closing.
