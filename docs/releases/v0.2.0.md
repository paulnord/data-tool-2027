Data Tool 2027 **0.2.0** is a general-purpose application for graphing and fitting numerical data locally.

**[Run in your browser — including Chromebooks](https://paulnord.github.io/data-tool-2027/)** · **[Download example files](https://github.com/paulnord/data-tool-2027/releases/download/v0.2.0/examples.zip)**

No account is required. Fitting runs locally; measurements are not uploaded. Internet is needed to open or reload the browser app. Save your session before closing the tab.

## Changes since the first desktop preview

- Twelve published datasets, each with CSV data, a configured `.trksess` analysis and documentation. The `published` folder includes ASASSN-14li light curves, chromium Rydberg energies, BESIII cross sections, pulsar/PWN correlations, ion-chamber response, radioactive decay and smoothed water viscosity.
- Explicit comparisons between reproduced fits and published results, including differences in weighting, data selection and uncertainty conventions. Unresolved discrepancies are identified without attributing an error to the authors.
- Automatic vertical axes follow plotted values with modest padding, without forcing zero into view. Clean tick marks, manual Y limits and zoom, and separate Log X / Log Y checkboxes improve graph inspection.
- Up to five manually selected fitting intervals. Fit controls sit beside interval selection; supplied Millikan data retains its missing observations and declared units.
- Long source notes use a numbered appendix, with visible sheet boundaries in preview and explicit print page breaks. Data and residual plots share the same printed width and horizontal scale. Compact summaries and fit-detail sections have clearer print layouts.
- Source columns survive uncertainty changes, exclusions and fitting. Unit entry preserves case, such as `m` and `mH`.
- A general-purpose numerical-methods guide explains capabilities, validation, uncertainty assumptions and scope, with NIST, Bevington, GUM, EA-4/02 and AAPT references.

## Using and saving your data

Choose **Data → Load file**, then browse the Examples directory or open your own file. A CSV retains data without preselecting a fit; a `.trksess` file includes analysis settings. Published examples are in the **published** subfolder. Inspect the graph, fit explicitly, and review residuals and uncertainty assumptions.

Single-fit sessions and source CSVs can be saved. Multi-interval and collision setups remain in-memory drafts: copy or print those reports before closing. Separate fits do not estimate covariance between intervals. X-error fitting and complete systematic uncertainty budgets are outside the implemented fit model. Nonlinear convergence and local uncertainty approximations require review.

The existing Tracker request/ack v1 protocol and `.trksess` v1–v3 compatibility are preserved. Tracker remains a separate application.

## Validation

The release is checked with numerical regression and coverage tests, browser workflows, the hosted web build, and native host tests on the three packaging platforms. The test PDF keeps the Rydberg summary together and preserves all comments across numbered notes pages. Interactive Windows/Linux desktop operation and every printer/OS combination are not claimed as tested.
